GITHUB WORK, THROUGH CHATGPT

GitHub changes.
By asking.

RepoPilot adds a repeatable delivery workflow around connected GitHub tools: inspect the right repository, make focused changes, check CI and review the diff, then verify delivery when available. It adds workflow guidance—not extra GitHub permissions—and reports what was actually verified.

What needs doing?

Copy a prompt, swap in your details and send it in ChatGPT.

FIX A BUG

Inspect owner/repo, find the root cause, fix it, run the relevant tests and open a pull request.

UNDERSTAND A REPO

Explain this repo’s structure, key dependencies, test commands and biggest maintenance risks.

FIX CI

Investigate the latest failed GitHub Actions run, fix the cause where possible and verify the result.

RepoPilot works within the access and tools available to your session. It never claims a change or test succeeded without evidence.
